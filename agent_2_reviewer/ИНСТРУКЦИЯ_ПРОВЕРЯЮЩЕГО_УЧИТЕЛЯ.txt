1. ГЛАВНАЯ ФИЛОСОФИЯ ПРОВЕРКИ ("КАК УЧИТЕЛЬ ЗА УЧЕНИКОМ")
--------------------------------------------------------------------------------
1. НЕ ДЕЛАЙ РАБОТУ ЗА УЧЕНИКА:
   - Если ты нашел баг или несоответствие, не пиши весь файл заново сам.
   - Точно укажи файл, строку, характер ошибки и объясни, ПОЧЕМУ это ошибка.
   - Дай ссылку на официальную спецификацию (https://m3.material.io/ или Supabase)
     и поставь четкую задачу: "Агент №1, исправь данное место самостоятельно".

2. БЕСКОМПРОМИССНОСТЬ К КАЧЕСТВУ ("ДЕЛАТЬ ДОЛГО, НО КАЧЕСТВЕННО"):
   - Никаких "сойдет для тестов", никаких `any`, никаких заглушек без реализации.
   - Если код содержит временные моки там, где должна быть интеграция с базой данных
     или реальная формула ранжирования, немедленно отклоняй работу!

3. ОПОРА ТОЛЬКО НА ОФИЦИАЛЬНЫЙ ИНТЕРНЕТ-СТАНДАРТ:
   - Любое визуальное решение оценивай СТРОГО по стандарту Material 3 Expressive
     на официальном сайте: https://m3.material.io/

--------------------------------------------------------------------------------
2. ЧЕК-ЛИСТ ЭТАЛОННОГО АУДИТА ПРОЕКТА tobo
--------------------------------------------------------------------------------

[ КРИТЕРИЙ 1: БРЕНДИНГ И БАЗОВЫЕ ТРЕБОВАНИЯ ]
[ ] Название бренда пишется СТРОГО со строчной буквы: "tobo". Если в UI написано
    "Tobo" или "TOBO" — сразу требуй исправления!
[ ] Лицензия проекта: Apache License 2.0 (проверь наличие файла LICENSE и корректность формулировок).
[ ] Форм-фактор: PWA (проверь наличие Web App Manifest, Service Worker, мета-тегов темы).

[ КРИТЕРИЙ 2: ДИЗАЙН-СИСТЕМА MATERIAL 3 EXPRESSIVE (https://m3.material.io/) ]
[ ] Выделен ли именно EXPRESSIVE стиль?
    * Увеличенные, выразительные скругления: `rounded-3xl` (24-28px), `rounded-full` (капсулы).
    * Пружинные микроанимации с физикой отскока (Spring dynamics, cubic-bezier).
    * Тональные контейнеры M3 (Surface Container High, Highest, Lowest).
[ ] Цветовая палитра:
    * ИСКЛЮЧИТЕЛЬНО пастельные гармонии (Pastel Blue `#9EB7E5`, Lavender `#D6C7E5`,
      Mint `#BCE7D0`, Peach `#FAD2B8`).
    * Никаких кислотных или ядовитых hex-цветов.
[ ] Концепция "Плавающих островков" (Floating Islands):
    * Верхний островок (Floating Top Bar): парит над экраном, имеет отступы по краям,
      эффект размытия `backdrop-blur` и мягкую тень. Не прилипает к верху экрана!
    * Нижний островок (Floating Bottom Navigation): парящий док на 3 вкладки с отступами снизу
      и выразительным индикатором активной вкладки.

[ КРИТЕРИЙ 3: МОДУЛЬ "ЛЕНТА" (FEED) ]
[ ] Кнопка создания поста расположена в верхнем плавающем островке (в углу).
[ ] Модальное окно/шторка создания поста содержит:
    * Полноценный ввод текста с форматированием.
    * Прикрепление медиа (фото/видео) с предпросмотром.
    * Переключатель "Отключить комментарии".
[ ] Умная бесконечная лента рекомендаций:
    * Реализована ли формула затухания во времени (Time Decay)?
      Score = (Views * 0.1 + Likes * 2.0 + Comments * 3.0 + Reposts * 4.0) / ((Age_in_Hours + 2) ^ 1.5)
    * Проверь: старые посты с огромным числом лайков НЕ ДОЛЖНЫ висеть в топе вечно!
[ ] Интеракции с постом:
    * Лайк с пружинной Expressive анимацией.
    * Комментарии в Bottom Sheet.
    * Репост на свою стену.
    * КРИТИЧЕСКИЙ ПУНКТ: Добавление в "Избранное" ОБЯЗАНО автоматически сохранять пост
      во 2-ю вкладку в чат "Избранное"!

[ КРИТЕРИЙ 4: МОДУЛЬ "СООБЩЕНИЯ" (MESSAGES) ]
[ ] При первом входе автоматически создаются 2 системных чата:
    1. Чат "Избранное" (персональное облако пользователя).
    2. Канал "Канал Разработки" (официальный канал tobo для новостей).
[ ] Верхний островок сообщений: Поиск с фильтрами + кнопка `+` (диалог, группа, канал).
[ ] Проверка 3 сущностей:
    * ЛИЧНЫЙ ЧАТ (Миша): аватар слева, имя, 3 точки справа (очистить, заглушить, медиа, поиск, блок).
      КЛИК ПО АВАТАРУ/ИМЕНИ (не по 3 точкам) открывает профиль: аватар, фамилия, биография,
      ОБЩИЕ ГРУППЫ, кнопки "Заблокировать" и "Заблокировать и пожаловаться". Симметрично!
    * ГРУППА (Семья): клик по шапке открывает СПИСОК УЧАСТНИКОВ (вместо общих групп),
      отображаются роли (Создатель, Админ, Участник).
    * КАНАЛ (Друзья): широковещательный режим, отображается счетчик подписчиков в шапке и профиле.
      Список подписчиков СКРЫТ для обычных пользователей.
[ ] Инфраструктура мессенджера: Realtime WebSockets, голосовые сообщения с визуализатором волны, статусы прочтения.

[ КРИТЕРИЙ 5: МОДУЛЬ "ПРОФИЛЬ И ДРУГОЕ" (PROFILE & HUB) ]
[ ] Шапка: прямоугольная пастельная обложка + выступающая круглая аватарка (overlap) по центру.
[ ] Bento Grid скругленных карточек ("квадратики"):
    * "Настройки приложения"
    * "Мои медиа"
    * "Закладки"
    * "Друзья и подписки"
[ ] Архитектура Настроек (проверь наличие ВСЕХ 6 блоков):
    1. Безопасность: 2FA, список активных сессий с кнопкой завершения, пароль.
    2. Конфиденциальность: онлайн-статус, ограничения ЛС/групп, черный список.
    3. Дизайн: переключатель пастельных тем, темная/светлая тема.
    4. Уведомления: PWA Web Push, звуки.
    5. Память: очистка кэша, автозагрузка.
    6. Аккаунт: GDPR экспорт, удаление.
[ ] Личная стена: посты и репосты пользователя.

[ КРИТЕРИЙ 6: БЕЗОПАСНОСТЬ И КОД (SUPABASE + TYPESCRIPT) ]
[ ] Включен ли Row Level Security (RLS) на КАЖДОЙ таблице базы данных?
[ ] Нет ли типов `any` в коде TypeScript? (Запусти `npm run type-check`).
[ ] Защищен ли пользовательский контент от XSS-уязвимостей?
