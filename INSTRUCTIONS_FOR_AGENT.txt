1. ОБЩИЕ СВЕДЕНИЯ И КОНЦЕПЦИЯ ПРОДУКТА
--------------------------------------------------------------------------------
1.1. Наименование продукта: "tobo" (строго со строчной буквы: "tobo").
1.2. Форм-фактор: Progressive Web Application (PWA) с адаптивностью Mobile-First,
     Desktop-Ready, поддержкой Service Worker, автономного кэширования и Web Push Notifications.
1.3. Стек технологий:
     - Frontend: СВОБОДА ВЫБОРА ЗА АГЕНТОМ — Vue 3 (Vite + Vue 3 / Nuxt 3, Composition API,
       <script setup>, Pinia, TypeScript Strict Mode) ЛИБО React (Next.js / Vite + React, TypeScript Strict Mode).
       Агент выбирает тот фреймворк (например, Vue 3), на котором ему проще, чище и надежнее
       реализовать реактивную архитектуру, реактивное состояние и дизайн Material 3 Expressive.
     - UI/UX фреймворк: Material 3 Expressive (строго по стандарту https://m3.material.io/).
     - Backend & Database: Supabase (PostgreSQL, Row Level Security, Supabase Auth,
       Supabase Realtime WebSockets, Supabase Storage).
     - Контроль версий и CI/CD: GitHub (ветки feature/*, main, PR-ревью, GitHub Actions).
     - Хостинг и Edge-инфраструктура: Vercel.
1.4. Лицензия проекта:
     - Выбрана лицензия: Apache License 2.0 (или MPL 2.0).
     - Обоснование: Строже классической MIT за счет наличия явного патентного соглашения
       (Patent Grant), защиты торговой марки ("tobo") и обязательного требования
       документирования внесенных изменений в исходные файлы, при сохранении гибкости
       для открытого и коммерческого развития.

2. ДИЗАЙН-СИСТЕМА: MATERIAL 3 EXPRESSIVE (M3 EXPRESSIVE)
--------------------------------------------------------------------------------
КРИТИЧЕСКОЕ ТРЕБОВАНИЕ: Дизайн разрабатывается ИСКЛЮЧИТЕЛЬНО по спецификации
Material 3 Expressive, доступной на официальном портале: https://m3.material.io/
Запрещено использовать устаревший Material 2 или стандартный базовый M3 без Expressive-модификаторов!

2.1. Философия Expressive:
     - Асимметричные и увеличенные радиусы скругления (Shape Scale: Extra Large, Full/Pill).
     - Выразительные тактильные микро-анимации с пружинной физикой (Spring Dynamics,
       Expressive Motion Curves: Emphasized Accelerate/Decelerate).
     - Многослойные адаптивные поверхности (Surfaces) с выразительными тональными
       контейнерами (Surface Container Lowest, Low, Normal, High, Highest).

2.2. Цветовая палитра:
     - Пастельные тона (Pastel Tones): Низкая насыщенность (low-chroma), мягкие, воздушные
       тональные оттенки, исключающие кричащие и токсичные цвета.
     - Основные пастельные гармонии:
       * Primary / Pastel Blue: Нежно-васильковый / лазурный пастельный (#9EB7E5 / тона 80-90).
       * Secondary / Pastel Lavender: Лавандово-сиреневый (#D6C7E5).
       * Tertiary / Pastel Mint & Peach: Мятный пастельный (#BCE7D0) и персиковый (#FAD2B8).
       * Surface & Background: Мягкие молочно-пудровые тона в светлой теме (#F9F9FB, #F3F3F7)
         и бархатно-графитовые пастельные тона в темной теме (#1A1C1E, #232529).

2.3. Архитектура "Плавающих островков" (Floating Islands):
     - Верхний плавающий островок (Floating Top App Bar Island):
       * Отделен от верхнего края экрана (отступ top: 12-16px, mx: 16px).
       * Форма: вытянутая капсула (pill-shaped, rounded-full) или скругленный прямоугольник (rounded-3xl).
       * Эффект: фоновое размытие (backdrop-filter: blur(16px)), мягкая Expressive тень (Elevation Level 2-3).
       * Наполнение: контекстные действия, аватар, статус, заголовок, поиск, кнопка создания.
     - Нижний плавающий островок навигации (Floating Bottom Navigation Island):
       * Плавающий док (Dock Pill), приподнятый над нижним краем экрана (bottom: 16-20px, mx: 20px).
       * 3 основные вкладки:
         1. Лента (Feed) - иконка Home / Feed.
         2. Сообщения (Messages) - иконка Chat / Forum.
         3. Профиль и другое (Profile & More) - иконка Account / Bento Hub.
       * Индикатор активной вкладки: Expressive Pill Indicator с плавным морфингом при переключении.

3. ФУНКЦИОНАЛЬНЫЙ МОДУЛЬ 1: ЛЕНТА (FEED)
--------------------------------------------------------------------------------
3.1. Структура экрана:
     - Верхний островок: Логотип "tobo", счетчик новых событий, а в правом углу — кнопка создания поста
       (Expressive Floating Action Button или Icon Button со знаком "+").
     - Основная область: Вертикальный виртуализированный бесконечный скролл с постами (Virtual Scrolling).

3.2. Создание поста (Post Creation):
     - Модальное окно или Expressive Fullscreen Sheet.
     - Текстовый редактор с поддержкой разметки (форматирование, заголовки, эмодзи, упоминания @username).
     - Прикрепление медиа:
       * Фотографии и видеофайлы с предпросмотром, индикатором загрузки и возможностью удаления.
       * Клиентская компрессия изображений (WebP) перед отправкой в Supabase Storage (bucket `post-media`).
     - Тумблер настроек:
       * "Отключить комментарии" (disable_comments: boolean).
       * Приватность публикации (для всех, только для друзей).
     - Валидация публикации: предотвращение публикации пустых постов, защита от флуда.

3.3. Алгоритмическая лента рекомендаций (Dynamic Dynamic Recommendation Feed):
     - Принцип работы: Лента ранжируется динамически на основе вовлеченности с обязательным
       экспоненциальным затуханием во времени (Time Decay), чтобы популярные посты не застревали в топе вечно.
     - Математическая модель ранжирования (базовый скоринг в PostgreSQL / Edge Function):
       Score = (Views * 0.1 + Likes * 2.0 + Comments * 3.0 + Reposts * 4.0) / ((Age_in_Hours + 2) ^ 1.5)
     - Лента динамически обновляется при скролле и периодическом фоновом рефреше.

3.4. Интеракции с постом:
     - Лайк (Like): кнопка с пружинной Expressive анимацией, мгновенный оптимистичный UI, счетчик лайков.
     - Комментарии (Comments): открытие модальной шторки (M3 Bottom Sheet) с веткой обсуждений,
       ответами на комментарии и поддержкой правки/удаления автором.
     - Избранное (Bookmark / Save):
       * ПРИ НАЖАТИИ "В ИЗБРАННОЕ" ПОСТ АВТОМАТИЧЕСКИ ОТПРАВЛЯЕТСЯ В ЧАТ "Избранное" ВО 2-Й ВКЛАДКЕ (СООБЩЕНИЯ)!
       * В чате "Избранное" появляется интерактивная карточка поста с возможностью быстрого перехода к оригиналу.
     - Репост (Repost / Share):
       * Возможность отправить пост на свою стену (появляется в профиле и попадает в ленту друзьям).
       * Возможность отправить пост напрямую в личный чат или группу.

4. ФУНКЦИОНАЛЬНЫЙ МОДУЛЬ 2: СООБЩЕНИЯ (MESSAGES)
--------------------------------------------------------------------------------
4.1. Главный экран сообщений:
     - Верхний плавающий островок:
       * Кнопка "Поиск" (раскрывает M3 Expressive Search Bar с фильтрами: Все, Чаты, Группы, Каналы).
       * Кнопка "+" (Add/Create) с выпадающим меню:
         - "Создать личный диалог"
         - "Создать группу"
         - "Создать канал"
     - Предустановленные системные чаты по умолчанию (First-run bootstrap для каждого пользователя):
       1. Чат "Избранное" — персональное облачное хранилище, куда сохраняются заметки, медиа и посты из Ленты.
       2. Канал "Канал Разработки" — официальный системный канал tobo, где публикуются новости, обновления,
          анонсы и changelog проекта. Доступен только для чтения пользователям, публикации делает админ.

4.2. Модели сущностей диалогов:
     А. ЛИЧНЫЙ ДИАЛОГ (Direct Chat, пример: "Миша"):
        - Верхний островок чата:
          * Слева: Аватарка собеседника и Имя (с индикатором онлайн/офлайн).
          * Справа: Меню "3 точки" (M3 Dropdown Menu):
            1) Очистить историю сообщений.
            2) Отключить уведомления (Mute).
            3) Поиск по переписке.
            4) Медиа чата (фото/видео/файлы).
            5) Заблокировать пользователя.
        - Интерактивная зона заголовка (Клик по аватару/имени — НЕ по 3 точкам):
          * Открывает детальную карточку/вкладку профиля собеседника:
            - Полноразмерный аватар.
            - Имя и Фамилия (если указана).
            - Биография / Описание (Bio).
            - Блок "Общие группы" с данным контактом.
            - Кнопка "Заблокировать".
            - Кнопка "Заблокировать и пожаловаться" (открывает выбор причины: Спам, Оскорбления, Мошенничество).
        - Симметричность: Собеседник (Миша) видит ровно такую же карточку текущего пользователя.

     Б. ГРУППА (Group Chat, пример: "Семья"):
        - Верхний островок: Аватарка группы, Название, количество участников ("5 участников, 2 в сети"), "3 точки".
        - Интерактивная зона заголовка:
          * Открывает профиль группы:
            - Аватар и название группы.
            - Описание группы.
            - ВМЕСТО общих групп отображается: ПОЛНЫЙ СПИСОК УЧАСТНИКОВ ГРУППЫ.
            - Индикаторы ролей: Владелец (Owner), Администратор (Admin), Участник (Member).
            - Для создателя/администраторов: кнопки "Добавить участников", "Назначить администратором",
              "Удалить из группы", настройка разрешений (кто может отправлять сообщения/медиа).

     В. КАНАЛ (Broadcast Channel, пример: "Друзья"):
        - Модель вещания: Один ко многим (публикации только от создателя и назначенных редакторов).
        - Верхний островок: Аватар канала, Название, счетчик подписчиков ("1 240 подписчиков").
        - Интерактивная зона заголовка:
          * Открывает профиль канала:
            - Аватар, Название, Описание, публичная ссылка (@channel_name).
            - Счетчик подписчиков (актуальное число).
            - Архив медиа и ссылок.
            - Уведомления (Вкл/Выкл звук).
            - Список участников скрыт для обычных подписчиков в целях конфиденциальности.
          * Для владельца канала:
            - Расширенная панель публикации (форматирование, отложенные посты, тихие посты без звука).
            - Статистика просмотров публикаций.

4.3. Базовая инфраструктура мессенджера (Realtime):
     - Сообщения на базе Supabase Realtime (WebSocket pub/sub).
     - Статусы доставки: Отправлено (одна галочка), Прочитано (две галочки).
     - Индикаторы набора текста ("Миша печатает...").
     - Голосовые сообщения с записью через Web Audio API и пастельным визуализатором волны.
     - Прикрепление фото, видео и документов.

5. ФУНКЦИОНАЛЬНЫЙ МОДУЛЬ 3: ПРОФИЛЬ И ДРУГОЕ (PROFILE & HUB)
--------------------------------------------------------------------------------
5.1. Шапка профиля:
     - Прямоугольная плашка-баннер (Cover Banner) в пастельных тонах (например, нежно-лазурный или лавандовый).
     - Круглая аватарка пользователя расположена по центру, выступая (наполовину перекрывая) нижний край плашки.
     - Клик по аватарке / плашке: просмотр в полном размере или переход к редактированию профиля.
     - Информационный блок:
       * Имя и Фамилия.
       * Уникальный юзернейм (@username).
       * Биография / Статус.
       * Кнопка "Редактировать профиль" (смена аватара, обложки, био, имени).

5.2. Bento Grid / Экспрессивные плитки-виджеты ("Квадратики" сервисов):
     Ниже шапки расположен адаптивный грид из скругленных карточек (M3 Expressive Cards):
     - Плитка 1: "Настройки приложения" (App Settings) — главный узел конфигурации.
     - Плитка 2: "Закладки и Избранное" — быстрый переход к сохраненным материалам.
     - Плитка 3: "Мои медиа" — галерея загруженных фото и видео.
     - Плитка 4: "Друзья и Подписки" — списки контактов и каналов.
     - Плитка 5: "Архив историй и записей".

5.3. Детальная архитектура настроек (Settings Architecture):
     Раздел "Настройки" должен включать в себя профессиональные подразделы:
     А. Безопасность (Security):
        - Двухфакторная аутентификация (2FA через TOTP Authenticator или Email-коды).
        - Активные сессии (Active Sessions): список устройств, браузеров, IP-адресов и кнопка "Завершить все другие сеансы".
        - Смена пароля и управление способами входа.
     Б. Конфиденциальность (Privacy):
        - "Кто видит мой статус 'В сети'": Все / Только друзья / Никто.
        - "Кто может писать мне сообщения": Все / Только друзья.
        - "Кто может добавлять меня в группы": Все / Только друзья.
        - Черный список (управление заблокированными пользователями с возможностью разблокировки).
     В. Дизайн и Темизация (Appearance & Design):
        - Выбор пастельной палитры:
          * Pastel Sky (Голубой)
          * Pastel Lavender (Лаванда)
          * Pastel Mint (Мята)
          * Pastel Peach (Персик)
        - Режим темы: Светлая / Темная / Системная (темная тема выполнена в мягких графитовых тонах).
        - Размер шрифта (Scale 90% / 100% / 115%).
     Г. Уведомления и Звуки (Notifications & Sounds):
        - PWA Push-уведомления (переключатель разрешений браузера).
        - Раздельная настройка уведомлений для личных сообщений, групп и каналов.
        - Звуковые оповещения и вибрация.
     Д. Данные и Память (Data & Storage):
        - Размер локального кэша (IndexedDB / Cache API).
        - Кнопка "Очистить кэш медиа".
        - Автозагрузка медиа (Всегда / Только по Wi-Fi / Никогда).
     Е. Учетная запись (Account):
        - Привязанная почта и телефон.
        - Выгрузка персональных данных архивом (GDPR Export).
        - Удаление аккаунта (с подтверждением паролем).

5.4. Личная стена пользователя:
     - Под Bento-плитками располагается вкладка "Мои записи" и "Репосты".
     - Публикации пользователя оформлены в едином стиле с главной Лентой.

6. АРХИТЕКТУРА БАЗЫ ДАННЫХ И БЕЗОПАСНОСТЬ (SUPABASE POSTGRESQL + RLS)
--------------------------------------------------------------------------------
Все таблицы в Supabase ОБЯЗАНЫ иметь включенный Row Level Security (RLS).
Прямой доступ без политик безопасности категорически запрещен!

6.1. Основные сущности базы данных:
     - `profiles`:
       * id (uuid, references auth.users on delete cascade, primary key)
       * username (text, unique)
       * first_name (text)
       * last_name (text, nullable)
       * avatar_url (text)
       * cover_url (text)
       * bio (text)
       * updated_at, created_at (timestamptz)
     - `posts`:
       * id (uuid, primary key, default gen_random_uuid())
       * author_id (uuid, references profiles(id))
       * content (text)
       * media_urls (jsonb / text[])
       * disable_comments (boolean, default false)
       * likes_count, comments_count, reposts_count, views_count (bigint, default 0)
       * created_at (timestamptz)
     - `post_likes` & `post_reposts`:
       * user_id, post_id, created_at
     - `comments`:
       * id, post_id, author_id, text, parent_id (для тредов), created_at
     - `chats`:
       * id (uuid, primary key)
       * type (enum: 'direct', 'group', 'channel', 'saved')
       * title (text, nullable для direct)
       * avatar_url (text, nullable)
       * description (text, nullable)
       * created_by (uuid, references profiles(id))
       * created_at (timestamptz)
     - `chat_members`:
       * chat_id (uuid, references chats(id))
       * user_id (uuid, references profiles(id))
       * role (enum: 'owner', 'admin', 'member')
       * joined_at (timestamptz)
     - `messages`:
       * id (uuid, primary key)
       * chat_id (uuid, references chats(id))
       * sender_id (uuid, references profiles(id))
       * content (text)
       * media_urls (jsonb)
       * is_read (boolean, default false)
       * forwarded_post_id (uuid, nullable, references posts(id))
       * created_at (timestamptz)
     - `blocked_users`:
       * blocker_id (uuid), blocked_id (uuid), reason (text), created_at

7. ШЕСТЬ КОРНЕВЫХ ПРАВИЛ И РЕГЛАМЕНТ ДЛЯ ИИ-АГЕНТА
--------------------------------------------------------------------------------
При выполнении любых задач агент ОБЯЗАН строго следовать данным 6 правилам:

ПРАВИЛО 1 (КОГНИТИВНЫЙ ЦИКЛ РАЗРАБОТКИ):
"Подумал -> Еще подумал -> Сделал -> Подумал -> Проверил -> Доделал -> Подумал -> Сказал"
- Ни одно действие, строка кода или архитектурное решение не принимаются импульсивно.
- Перед кодом — глубокий системный анализ зависимостей и краевых случаев.
- После написания кода — критическая самопроверка на синтаксис, типизацию, безопасность и UX.
- Перед финальным ответом — проверка соответствия ТЗ и четкий отчет.

ПРАВИЛО 2 (ПРИОРИТЕТ КАЧЕСТВА НАД СКОРОСТЬЮ):
"Делай долго, но качественно"
- Запрещены временные костыли ("TODO: доделать позже", псевдо-моки в боевом коде).
- Полная типизация TypeScript (никаких `any`), строгая обработка ошибок (Error Boundaries, Try/Catch, Fallbacks).
- Архитектура должна быть масштабируемой и поддерживаемой.

ПРАВИЛО 3 (АКТУАЛЬНОСТЬ ИСТОЧНИКОВ И ПРОВЕРКА ЧЕРЕЗ ИНТЕРНЕТ):
"Полагайся на актуальную документацию, а не на домыслы"
- Любые спецификации компонентов Material 3 Expressive сверять ТОЛЬКО с https://m3.material.io/
- Использовать официальную документацию Supabase, PWA Web APIs, Vue 3 / Nuxt 3 / React.
- При малейших сомнениях в сигнатуре API — верифицировать информацию, а не галлюцинировать.

ПРАВИЛО 4 (СТРОГАЯ МОДУЛЬНОСТЬ И РАЗДЕЛЕНИЕ ОТВЕТСТВЕННОСТИ - SRP):
- Разделять UI-компоненты, слой бизнес-логики (хуки / composables / Pinia-хранилища) и сервисы запросов к API/Supabase.
- Максимальный размер одного файла не должен превышать разумные пределы (до 250-300 строк).
- Переиспользуемые дизайн-компоненты (плавающие островки, кнопки, шторки) изолировать в `@/components/ui/`.

ПРАВИЛО 5 (БЕЗОПАСНОСТЬ ZERO-TRUST И ЦЕЛОСТНОСТЬ ДАННЫХ):
- Никогда не доверять клиентскому коду: вся валидация дублируется через схемы (Zod) и RLS-политики.
- Санитизация Rich Text перед рендерингом для исключения XSS-уязвимостей.
- Защита медиа-загрузок: проверка MIME-типов и ограничений размеров на уровне Storage Policies.

ПРАВИЛО 6 (ЧИСТОТА ДИЗАЙН-ТОКЕНОВ M3 EXPRESSIVE):
- Запрещены произвольные "магические числа" для отступов, скруглений и цветов.
- Все цвета, радиусы (rounded-full, rounded-3xl), тени и переходы должны ссылаться
  на системные дизайн-токены пастельной палитры tobo и спецификацию M3 Expressive.
