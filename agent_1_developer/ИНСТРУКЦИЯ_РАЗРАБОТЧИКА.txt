--------------------------------------------------------------------------------
1. СТЕК ТЕХНОЛОГИЙ И АРХИТЕКТУРНАЯ СВОБОДА
--------------------------------------------------------------------------------
1.1. Базовый стек проекта (уже инициализирован в проекте):
     - Frontend: Vue 3 (Composition API, `<script setup>`, TypeScript Strict Mode).
       (Тебе также открыта свобода использовать React / Next.js, если ты обоснуешь выбор,
       но текущий проект уже настроен на Vue 3 + Vite + Pinia).
     - Стейт-менеджмент: Pinia stores с типизированным состоянием.
     - Стилизация: Tailwind CSS + Дизайн-токены Material 3 Expressive.
     - PWA: `vite-plugin-pwa`, Service Worker, offline-кэш, Web App Manifest.
     - Backend & DB: Supabase (PostgreSQL, Row Level Security, Realtime WebSockets, Storage).
     - Хостинг и CI/CD: Vercel + GitHub.
     - Лицензия: Apache License 2.0.

--------------------------------------------------------------------------------
2. ДИЗАЙН-СИСТЕМА: MATERIAL 3 EXPRESSIVE (СТРОГО https://m3.material.io/)
--------------------------------------------------------------------------------
КРИТИЧЕСКОЕ ТРЕБОВАНИЕ: Агент №2 будет строго проверять каждый твой компонент
по стандартам https://m3.material.io/. Если ты используешь обычный плоский дизайн
или забудешь про Expressive-модификаторы, работа будет отклонена!

2.1. Особенности Material 3 Expressive:
     - Скругления: увеличенные и асимметричные радиусы (rounded-3xl: 24-28px, rounded-full: капсулы).
     - Динамика: выразительные пружинные микроанимации (Spring physics, cubic-bezier с отскоком).
     - Поверхности: тональные контейнеры Surface Container (Lowest, Low, High, Highest).
2.2. Пастельная цветовая палитра:
     - Название бренда: строго со строчной буквы — `tobo`.
     - Цвета: мягкие, нежные пастельные оттенки (Pastel Blue `#9EB7E5`, Lavender `#D6C7E5`,
       Mint `#BCE7D0`, Peach `#FAD2B8`, молочно-пудровые фоны в светлой теме и глубокие
       бархатно-графитовые в темной теме). Никаких кислотных оттенков!
2.3. Плавающие островки (Floating Islands):
     - Верхний островок (Floating Top App Bar): парящая капсула с отступом от верха экрана,
       backdrop-filter: blur(16px), контекстные кнопки и аватар.
     - Нижний островок (Floating Bottom Navigation Bar): парящий док на 3 вкладки над низом экрана
       с анимированным индикатором активной вкладки.

--------------------------------------------------------------------------------
3. ТРИ ОСНОВНЫЕ ВКЛАДКИ
--------------------------------------------------------------------------------
ВКЛАДКА 1: "ЛЕНТА" (FEED)
- Верхний островок: логотип `tobo`, в правом углу — Expressive кнопка создания поста.
- Создание поста: редактор текста, прикрепление фото/видео с компрессией, тумблер "Отключить комментарии", приватность.
- Алгоритмическая лента: бесконечный скролл с динамическим ранжированием и ОБЯЗАТЕЛЬНЫМ
  затуханием во времени (Time Decay), чтобы популярные посты не висели вечно:
  Score = (Views * 0.1 + Likes * 2.0 + Comments * 3.0 + Reposts * 4.0) / ((Age_in_Hours + 2) ^ 1.5)
- Интеракции:
  * Лайк с M3 пружинной анимацией.
  * Комментарии в Bottom Sheet.
  * Репост друзьям на стену и в чаты.
  * В ИЗБРАННОЕ: пост автоматически отправляется в чат "Избранное" во 2-й вкладке (Сообщения)!

ВКЛАДКА 2: "СООБЩЕНИЯ" (MESSAGES)
- Системный автостарт (чаты по умолчанию):
  1. "Избранное" — персональное облако заметок, файлов и сохраненных постов из Ленты.
  2. "Канал Разработки" — официальный системный канал tobo с новостями и обновлениями.
- Верхний островок: Поиск (с фильтрами: Чаты, Группы, Каналы) и кнопка `+` (создать диалог, группу, канал).
- 3 сущности:
  1. Личный чат (Миша): аватар, имя, статус. Справа меню "3 точки" (очистить, заглушить, медиа, поиск, блок).
     Клик по аватару/имени открывает карточку профиля: био, общие группы, кнопки "Заблокировать" и "Заблокировать и пожаловаться". Симметрично для обоих пользователей.
  2. Группа (Семья): многопользовательский чат, управление ролями. Клик по шапке открывает СПИСОК УЧАСТНИКОВ вместо общих групп.
  3. Канал (Друзья): широковещательный режим, счетчик подписчиков в шапке и профиле. Список участников скрыт для подписчиков.
- Realtime WebSockets, голосовые сообщения с визуализацией волны, статусы прочтения.

ВКЛАДКА 3: "ПРОФИЛЬ И ДРУГОЕ" (PROFILE & HUB)
- Шапка профиля: прямоугольная пастельная обложка, выступающая круглая аватарка (overlap), имя, био, редактирование.
- Bento Grid ("Квадратики" сервисов):
  * "Настройки приложения" (главный модуль).
  * "Мои медиа" (галерея).
  * "Закладки" (Избранное).
  * "Друзья и подписки".
- Полная архитектура Настроек:
  * Безопасность: 2FA, активные сессии с кнопкой завершения, пароль.
  * Конфиденциальность: онлайн-статус, ограничения ЛС и групп, черный список.
  * Дизайн: пастельные темы (Sky, Lavender, Mint, Peach), темная/светлая тема, шрифт.
  * Уведомления: PWA Web Push, звуки.
  * Память: очистка кэша, автозагрузка.
  * Учетная запись: GDPR экспорт данных, удаление.
- Личная стена записей и репостов.

5. ТВОИ ОБЯЗАТЕЛЬНЫЕ ПРАВИЛА РАЗРАБОТКИ
--------------------------------------------------------------------------------
1. Когнитивный цикл: "Подумал -> Еще подумал -> Сделал -> Подумал -> Проверил -> Доделал -> Подумал -> Сказал".
2. Делай долго, но качественно: никаких заглушек и `any`.
3. Опирайся на официальную документацию: только https://m3.material.io/ и официальные спецификации.
4. Модульность (SRP): изолируй компоненты, хранилища Pinia и сервисы Supabase.
5. Безопасность Zero-Trust: RLS и валидация Zod.
6. Чистота дизайн-токенов: только системные пастельные токены tobo.
