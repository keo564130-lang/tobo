# tobo — Социальная сеть и мессенджер нового поколения

> **tobo** (строго со строчной буквы) — прогрессивное веб-приложение (PWA) и кроссплатформенная социальная сеть, спроектированная в соответствии со стандартом **Material 3 Expressive** (https://m3.material.io/) в мягких гармоничных пастельных тонах, на базе **Vue 3, TypeScript, Pinia, Tailwind CSS** и облачной платформы **Supabase (PostgreSQL + Row Level Security + Realtime WebSockets)**.

Лицензия: **Apache License 2.0** (с патентным соглашением и защитой торгового знака tobo).

## 🌟 Ключевые особенности и дизайн-система

### 1. Стандарт Material 3 Expressive
- **Пастельная цветовая палитра (Low Chroma & High Harmony)**:
  - **Pastel Sky** (Нежно-васильковый / лазурный `#9EB7E5`) — основной акцент интерфейса.
  - **Pastel Lavender** (Лавандовый `#D6C7E5`) — вторичный мягкий акцент.
  - **Pastel Mint** (Мятный `#BCE7D0`) и **Pastel Peach** (Персиковый `#FAD2B8`) — гармоничные функциональные маркеры.
  - **Фоновые поверхности**: молочно-пудровая светлая тема (`#F9F9FB`) и бархатно-графитовая тёмная тема (`#131416`).
- **Архитектура плавающих островков (Floating Islands)**:
  - **Floating Top Bar Island**: плавающая капсула с эффектом матового стекла (`backdrop-blur-xl`), мягкой M3 тенью, контекстным поиском и действиями.
  - **Floating Bottom Navigation Island**: приподнятый плавающий док на 3 вкладки с выразительным пружинным индикатором активного раздела (Morphing Pill Indicator).
- **Expressive Motion**: пружинная физика микроанимаций (`cubic-bezier(0.34, 1.56, 0.64, 1)`), тактильный отклик при нажатиях (`m3-press-effect`).

## 📱 Функциональные модули (3 основные вкладки)

### Вкладка 1: "Лента" (Feed)
- **Алгоритмический скоринг рекомендаций с затуханием во времени (Time Decay)**:
  $$\text{Score} = \frac{\text{Views} \cdot 0.1 + \text{Likes} \cdot 2.0 + \text{Comments} \cdot 3.0 + \text{Reposts} \cdot 4.0}{(\text{Age\_in\_Hours} + 2)^{1.5}}$$
- **Создание постов**:
  - Клиентская компрессия изображений в **WebP** (`compressImageToWebP`) перед отправкой.
  - Тумблер *"Отключить комментарии"* (`disable_comments`).
  - Выбор аудитории: *"Для всех"* / *"Только для друзей"*.
- **Интеракции**:
  - Лайк с пружинной M3 анимацией сердца.
  - Комментарии в модальной шторке **M3 Expressive Bottom Sheet**.
  - Репост на свою личную стену.
  - **"В Избранное"**: мгновенно и автоматически отправляет пост во 2-ю вкладку в персональный чат **"Избранное"** с интерактивной карточкой-превью!

### Вкладка 2: "Сообщения" (Messages)
- **Системный старт по умолчанию**:
  1. Чат **"Избранное"** — персональное облако пользователя для заметок, аудио и постов из ленты.
  2. Канал **"Канал Разработки"** — официальный канал команды tobo с новостями и чейнджлогом.
- **3 сущности диалогов**:
  1. **Личный диалог (Direct Chat, например: "Миша")**:
     - Клик по аватару/имени открывает карточку собеседника: биографию (Bio), блок **"Общие группы"**, кнопки *"Заблокировать"* и *"Заблокировать и пожаловаться"* с модальным выбором причины (Спам, Оскорбления, Мошенничество). Симметричное отображение для собеседников.
  2. **Группа (Group Chat, например: "Семья")**:
     - Клик по заголовку открывает карточку группы: аватар, описание и **полный список участников с ролями** (Владелец, Админ, Участник) и панелью модерации.
  3. **Канал (Broadcast Channel, например: "Друзья")**:
     - Модель вещания (публикации только от владельца/редакторов). В шапке отображается счётчик подписчиков (*15 420 подписчиков*). Список подписчиков скрыт для обычной аудитории.
- **Инфраструктура**:
  - Голосовые сообщения через **Web Audio API** с записью амплитуды и пастельным визуализатором звуковой волны.
  - Индикаторы набора текста (*"Миша печатает..."*).
  - Статусы доставки: отправлено (одна галочка) / прочитано (две галочки).
  - Поиск с фильтрами: Все, Чаты, Группы, Каналы.

### Вкладка 3: "Профиль и другое" (Profile & Hub)
- **Шапка профиля**: пастельный Cover-баннер и выступающий круглый аватар (overlapping).
- **Bento Grid ("Квадратики" / Сервисный хаб)**:
  - ⚙️ *Настройки приложения*
  - 🔖 *Закладки и Избранное*
  - 🖼️ *Мои медиа*
  - 👥 *Друзья и подписки*
- **Личная стена**: записи автора и репосты.
- **Глубокая архитектура настроек**:
  - **Безопасность**: 2FA (TOTP Authenticator), активные сессии с завершением сторонних сеансов.
  - **Конфиденциальность**: видимость онлайна, ограничения переписки, управление Чёрным списком.
  - **Дизайн**: живой переключатель 4 пастельных тем (Sky, Lavender, Mint, Peach), тёмная/светлая тема, масштаб шрифтов (90%, 100%, 115%).
  - **Память**: расчет размера локального кэша IndexedDB, кнопка очистки кэша.
  - **Учетная запись**: экспорт всех данных в JSON (**GDPR Export**), удаление аккаунта.

## 🗄️ База данных и безопасность (Supabase PostgreSQL + RLS)

Схема базы данных находится в [`supabase/schema.sql`](supabase/schema.sql):
- **Таблицы**: `profiles`, `posts`, `post_likes`, `post_reposts`, `comments`, `chats`, `chat_members`, `messages`, `blocked_users`, `reports`, `active_sessions`.
- **Zero-Trust RLS**: Каждая таблица защищена строгими политиками доступа для `SELECT`, `INSERT`, `UPDATE`, `DELETE`.
- **Триггеры**:
  - `on_auth_user_created`: при регистрации пользователя автоматически создаётся профиль, инициализируется чат *"Избранное"* и подписка на *"Канал Разработки"*.
- **Функция алгоритма**: `get_ranked_feed(limit, offset)` с расчётом Time Decay на уровне БД.
- **Автономный / Демо режим**: При отсутствии подключения к облаку Supabase приложение автоматически использует реактивный локальный адаптер с полной персистентностью и богатыми демонстрационными данными.

## 🚀 Установка и запуск

### Требования
- Node.js >= 18.0.0
- npm >= 9.0.0

### Шаги установки

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/tobo.git
   cd tobo
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. (Опционально) Настройте Supabase в файле `.env`:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
   ```
   *(Если файл `.env` пустой, tobo запустится в полностью автономном оффлайн-режиме)*

4. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

5. Сборка для production:
   ```bash
   npm run build
   ```

## 📦 Развёртывание на Vercel

Проект оптимизирован для мгновенного развёртывания на платформе Vercel:
1. Загрузите репозиторий на GitHub.
2. В панели Vercel нажмите **Add New Project** и выберите репозиторий `tobo`.
3. Фреймворк определится автоматически как **Vite**.
4. Добавьте переменные окружения `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
5. Нажмите **Deploy**.
