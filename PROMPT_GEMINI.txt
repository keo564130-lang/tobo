--------------------------------------------------------------------------------
1. НЕПРЕЛОЖНЫЕ ПРАВИЛА ТВОЕЙ РАБОТЫ (6 ЗАКОНОВ РАЗРАБОТКИ)
--------------------------------------------------------------------------------
Ты ОБЯЗАН неукоснительно соблюдать следующие 6 правил в каждом цикле выполнения задач:

1. КОГНИТИВНЫЙ ЦИКЛ (8 ФАЗ ДЕЙСТВИЯ):
   "Подумал -> Еще подумал -> Сделал -> Подумал -> Проверил -> Доделал -> Подумал -> Сказал"
   - Ты никогда не начинаешь писать код "вслепую".
   - Сначала анализируешь контекст, архитектуру, влияние на другие компоненты и краевые случаи.
   - Пишешь реализацию.
   - Проводишь строгий аудит написанного (типы, безопасность, дизайн-токены, ошибки асинхронности).
   - Исправляешь любые недочеты.
   - Только после этого формулируешь четкий, структурированный и аргументированный ответ.

2. ПРИОРИТЕТ ВЫСОЧАЙШЕГО КАЧЕСТВА:
   "Делай долго, но качественно"
   - Запрещены поверхностные заглушки, моки без реализации и комментарии вида "// todo: дописать".
   - Только надежный, расширяемый и самодокументируемый код промышленного уровня.
   - Полноценная обработка ошибок (Error Boundaries, Try-Catch блоки, Toast-уведомления, Fallback UI).

3. АБСОЛЮТНЫЙ АВТОРИТЕТ ОФИЦИАЛЬНОЙ ДОКУМЕНТАЦИИ:
   "Полагайся на официальные спецификации, а не на фантазии"
   - По компонентам и дизайн-системе ориентируйся СТРОГО И ИСКЛЮЧИТЕЛЬНО на https://m3.material.io/
   - Не используй устаревший Material 2 или неспецифицированные классы.
   - Сверяйся с актуальной документацией Supabase, TypeScript, Vue 3 / Nuxt 3 / React и Web APIs.

4. СТРОГАЯ МОДУЛЬНОСТЬ (SINGLE RESPONSIBILITY PRINCIPLE):
   - Изолируй UI-слой, бизнес-логику (хуки / composables / Pinia stores) и слой работы с данными (сервисы Supabase).
   - Не создавай гигантских монолитных файлов — декомпозируй код на атомарные, понятные модули.

5. БЕЗОПАСНОСТЬ ZERO-TRUST И ЦЕЛОСТНОСТЬ ДАННЫХ:
   - Любая таблица базы данных Supabase обязана быть защищена Row Level Security (RLS).
   - Все входящие данные санируются для исключения XSS-уязвимостей.
   - Защита от SQL-инъекций и строгая валидация типов (Zod / TypeScript).

6. ЧИСТОТА ДИЗАЙН-ТОКЕНОВ И СТИЛЯ:
   - Запрещены случайные "магические" hex-цвета и хаотичные пиксели.
   - Все отступы, формы, радиусы и палитры берутся строго из дизайн-системы tobo на базе M3 Expressive.

--------------------------------------------------------------------------------
2. БРЕНДИНГ И ДИЗАЙН-СИСТЕМА: MATERIAL 3 EXPRESSIVE
--------------------------------------------------------------------------------
2.1. Имя бренда:
     Пишется СТРОГО со строчной буквы: "tobo" (не "Tobo", не "TOBO").

2.2. Стандарт интерфейса — MATERIAL 3 EXPRESSIVE:
     Выделяй и применяй именно EXPRESSIVE-версию Material 3 (https://m3.material.io/):
     - Асимметричные и выразительные радиусы скругления (Shape Scale: rounded-3xl, rounded-full / pill).
     - Динамика и глубина: многослойные тональные контейнеры (Surface Container High / Highest).
     - Выразительные пружинные микроанимации (Expressive Spring Physics, Emphasized Motion).

2.3. Цветовая палитра — ПАСТЕЛЬНЫЕ ТОНА:
     - Никаких ядовитых, кислотных и перенасыщенных оттенков!
     - Пастельные тональные гаммы (Low Chroma, Pastel Harmonious Tones):
       * Pastel Blue (Нежно-васильковый / лазурный): основной акцент для кнопок, активных состояний.
       * Pastel Lavender (Лавандовый): вторичный мягкий акцент для тегов, плашек и статусов.
       * Pastel Mint (Мятный) & Pastel Peach (Персиковый): вспомогательные тональные маркеры.
       * Пастельные нейтральные фоны: молочно-жемчужный в светлой теме, глубокий бархатно-графитовый в темной.

2.4. Архитектурная концепция: ПЛАВАЮЩИЕ ОСТРОВКИ (FLOATING ISLANDS):
     - Верхний плавающий островок (Floating Top Bar Island):
       Капсульная или скругленная (rounded-3xl) плавающая панель с отступом от краев экрана,
       эффектом матового стекла (backdrop-blur) и мягкой тенью.
     - Нижний плавающий островок навигации (Floating Bottom Bar Island):
       Плавающий док на 3 вкладки, приподнятый над низом экрана, с выразительным индикатором активной вкладки.

--------------------------------------------------------------------------------
3. СТРУКТУРА ПРИЛОЖЕНИЯ: 3 ОСНОВНЫЕ ВКЛАДКИ
--------------------------------------------------------------------------------

ВКЛАДКА 1: "ЛЕНТА" (FEED)
- Верхний островок: Логотип "tobo", уведомления, в углу — Expressive кнопка/FAB создания поста.
- Создание поста:
  * Rich-text редактор с форматированием, поддержкой медиа (фото/видео).
  * Клиентская компрессия и загрузка в Supabase Storage (`post-media`).
  * Тумблер "Отключить комментарии" и выбор аудитории.
- Алгоритмическая лента рекомендаций:
  * Бесконечный скролл с динамическим ранжированием на основе вовлеченности (просмотры, лайки, комментарии, репосты).
  * ОБЯЗАТЕЛЬНОЕ временное затухание (Time Decay), чтобы старые популярные посты не оставались на 1 месте вечно.
  * Формула: Score = (Views * 0.1 + Likes * 2.0 + Comments * 3.0 + Reposts * 4.0) / ((Age_in_Hours + 2) ^ 1.5).
- Интеракции:
  * Лайк с пружинной M3 микроанимацией.
  * Комментарии в Expressive Bottom Sheet.
  * РЕПОСТ: публикация на своей стене для друзей.
  * В ИЗБРАННОЕ: пост АВТОМАТИЧЕСКИ отправляется и сохраняется во 2-ю вкладку (Сообщения) в чат "Избранное".

ВКЛАДКА 2: "СООБЩЕНИЯ" (MESSAGES)
- Системный старт по умолчанию (создается автоматически для каждого пользователя):
  1. Чат "Избранное" — персональное облако пользователя для заметок, медиа и сохраненных постов из Ленты.
  2. Канал "Канал Разработки" — официальный системный канал tobo с новостями, анонсами и апдейтами.
- Верхний островок:
  * Кнопка "Поиск" (разворачивает M3 Search Bar с фильтрацией: Чаты, Группы, Каналы).
  * Кнопка "+" с меню: создать диалог, создать группу, создать канал.
- 3 ключевые сущности диалогов:
  1. ЛИЧНЫЙ ДИАЛОГ (Direct Chat, пример: "Миша"):
     * Верхний островок: Аватар слева, Имя, статус онлайна. Справа меню "3 точки" (очистить чат, поиск, медиа, заглушить).
     * КЛИК ПО ЗОНЕ ЗАГОЛОВКА (по аватару/имени): открывает карточку собеседника с биографией (Bio), ФИО,
       блоком "Общие группы", кнопками "Заблокировать" и "Заблокировать и пожаловаться" (с выбором причины).
     * Симметричность: собеседник видит аналогичный профиль текущего пользователя.
  2. ГРУППА (Group Chat, пример: "Семья"):
     * Многопользовательский чат, администрирование, роли (Создатель, Админ, Участник).
     * Клик по зоне заголовка открывает карточку группы: аватар, описание, настройки И ВМЕСТО ОБЩИХ ГРУПП —
       ПОЛНЫЙ СПИСОК УЧАСТНИКОВ с возможностью управления для админов.
  3. КАНАЛ (Broadcast Channel, пример: "Друзья"):
     * Модель вещания (публикации только от владельца/редакторов).
     * В шапке и профиле отображается счетчик подписчиков ("1 520 подписчиков").
     * Клик по зоне заголовка открывает информацию о канале. Список подписчиков скрыт от обычной аудитории.
- Базовая инфраструктура: Realtime веб-сокеты Supabase, индикаторы набора, статусы прочтения, голосовые сообщения с визуализацией волны, прикрепление файлов.

ВКЛАДКА 3: "ПРОФИЛЬ И ДРУГОЕ" (PROFILE & HUB)
- Шапка профиля:
  * Прямоугольная пастельная плашка-баннер (Cover).
  * Выступающая за нижнюю границу плашки круглая аватарка (overlap).
  * Имя, Фамилия, @username, биография, кнопка редактирования.
- Bento Grid ("Квадратики" / Сервисный хаб):
  * Выразительные скругленные карточки быстрой навигации:
    1) "Настройки приложения" (App Settings).
    2) "Мои медиа" (Галерея).
    3) "Закладки" (Избранное).
    4) "Друзья и подписки".
- Раздел "Настройки" (Глубокая архитектура):
  * Безопасность: 2FA (TOTP/Email), активные сессии с кнопкой сброса, смена пароля.
  * Конфиденциальность: видимость онлайна, ограничения на сообщения и группы, черный список.
  * Дизайн: переключатель пастельных тем (Sky, Lavender, Mint, Peach), светлая/темная тема, масштаб шрифтов.
  * Уведомления: PWA Web Push, звуки, раздельная настройка для чатов, групп, каналов.
  * Память: очистка медиа-кэша, управление автозагрузкой.
  * Учетная запись: экспорт данных (GDPR), удаление аккаунта.
- Личная стена: записи пользователя и репосты.

4. ТЕХНИЧЕСКИЙ СТЕК И ИНФРАСТРУКТУРА
--------------------------------------------------------------------------------
- Frontend-фреймворк: ВЫБОР ЗА ТОБОЙ (ИИ-АГЕНТОМ) — Vue 3 (Vite + Vue 3 / Nuxt 3, Pinia, Composition API,
  <script setup>, TypeScript Strict Mode) ИЛИ React (Next.js / Vite + React). Если тебе проще, элегантнее,
  чище и надежнее писать на Vue 3 — смело выбирай Vue 3. Главный критерий — максимальное инженерное качество,
  производительность и строгое воплощение стандарта Material 3 Expressive.
- Архитектура PWA: Manifest, Service Worker (Cache-First для статики, Network-First для API, offline fallback).
- База данных: Supabase PostgreSQL со строгими RLS-политиками для всех таблиц (`profiles`, `posts`, `chats`, `messages` и др.).
- Хостинг: Vercel. Репозиторий: GitHub.
- Лицензия: Apache License 2.0 (защита авторства, патентов и торговой марки "tobo").
